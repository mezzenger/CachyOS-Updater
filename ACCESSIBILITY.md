# Accessibility

All icon-only controls have accessible names and tooltips. Package lists and
status messages use selectable or standard GTK text controls, and color is not
the only status indicator.

Keyboard shortcuts:

- Ctrl+R: refresh update status
- Ctrl+U: review pending updates
- Ctrl+D: export diagnostics
- Ctrl+,: open settings
- Ctrl+Q: quit

Pacman authentication uses the desktop's accessible Polkit agent. Update output
is streamed into a selectable in-app text view.
